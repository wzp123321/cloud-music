## 播放器「唱到一半就切歌」诊断与修复（用户选 C 换源，落地 C + 真实 duration 校准）
- 现象：歌曲唱到一半（进度条显示才一半）就自动跳下一首。
- 根因：切歌只来自浏览器 `@ended`（play-controller.vue:28 → store/player.ts onEnded）与手动按钮；进度/「唱完」判定完全依赖接口 `dt`，全链路从不读取 `el.duration`/`loadedmetadata`。网易云对试听/会员/版权受限歌曲返回的音源真实时长 < `dt`（片段），浏览器在半首处 `ended` → 按播放模式切下一首，进度条却显示才一半。之前修的点歌重播/进度条回跳/切歌队列/首播竞态都没覆盖这条线。
- 后端 `server.js` 是标准 NeteaseCloudMusicApi，只反代 API，音频直连网易云 CDN，不截断音频字节，排除后端截断。
- 修复（3 文件）：
  1. `store/playlist.ts`：`queryMusicUrl` 由 `/song/url`(br) 改调 `/song/url/v1` + `level:'standard'`，对非会员更稳、更易拿完整音源。
  2. `store/player.ts`：新增 `realDuration`(ms) + `onLoadedMetadata`（loadedmetadata 读 `el.duration` 校准）；`onTimeUpdate` 进度改用 `realDuration || dt`；切歌点（switchMusic / play 新歌 / onEnded RANDOM）重置 `realDuration=0` 等新元数据；`onEnded` 加片段检测（`realDuration < dt*0.9` 时停止并提示「当前为试听片段，已停止播放」，不再静默切歌）。
  3. `play-controller.vue`：`<cm-audio>` 挂 `@loadedmetadata="player.onLoadedMetadata"`（cm-audio inheritAttrs:true，事件透传原生 audio，与现有 @ended/@timeupdate 同机制）。
- 边界：C 换源对「版权试听片段」不治本（片段由版权决定，换接口版本也只给片段），只能提示；真正消除「唱一半误切歌」错位的是真实 duration 校准。限时 URL 过期走 `@error`(onError 暂停+提示，不切歌)，非本次现象。
- 验证：`npx vue-tsc --noEmit` EXIT=0、`npx eslint` 三改动文件 0 error/0 warning。未跑 full build（避免 components.d.ts 副产物）；未做浏览器实测（沙箱无浏览器/网易云接口需 cookie），建议用户本地起 server+web 实测片段曲是否仍「唱一半」。
