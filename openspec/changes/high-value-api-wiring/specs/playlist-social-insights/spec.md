# Spec Delta

## Purpose

让歌单详情页展示订阅者与相关推荐歌单，使用户在歌单内即可发现贡献者与同好内容，并在数据缺失时优雅降级。

## ADDED Requirements

### Requirement: 订阅者列表展示
系统 SHALL 在歌单详情页展示该歌单的订阅者头像与昵称，条目数量以接口返回为准。

#### Scenario: 存在订阅者
- **WHEN** 用户打开一个存在订阅者的歌单详情页
- **THEN** 页面展示订阅者列表，每项包含头像与昵称

#### Scenario: 无订阅者
- **WHEN** 订阅者接口返回空列表
- **THEN** 页面隐藏订阅者区块，歌单信息、歌曲列表与评论区正常展示

### Requirement: 相关推荐展示
系统 SHALL 在歌单详情页底部展示与当前歌单相关的歌单推荐，每项可点击进入对应歌单详情。

#### Scenario: 点击相关推荐
- **WHEN** 用户点击一个相关推荐歌单
- **THEN** 页面跳转到该歌单的详情页

#### Scenario: 歌单切换
- **WHEN** 用户从当前歌单跳转到另一个歌单
- **THEN** 订阅者与相关推荐更新为新歌单对应的数据

### Requirement: 数据请求降级
系统 SHALL 在订阅者与相关推荐请求失败时隐藏对应区块，不额外弹错、不影响歌单主流程。

#### Scenario: 相关推荐接口失败
- **WHEN** 相关推荐请求失败
- **THEN** 页面隐藏相关推荐区块，歌单歌曲列表与播放操作不受影响
