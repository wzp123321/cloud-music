# Spec Delta

## Purpose

让歌曲详情页在既有歌词与评论之外展示歌曲百科摘要与红心数，并在数据缺失或接口失败时保持稳定可用。

## ADDED Requirements

### Requirement: 歌曲百科信息展示
系统 SHALL 在歌曲详情页的歌曲详情面板展示当前歌曲的百科摘要；接口返回的字段缺失时不展示对应条目。

#### Scenario: 百科信息可用
- **WHEN** 用户打开一首存在百科数据的歌曲详情页并切到「歌曲详情」面板
- **THEN** 面板展示该歌曲的百科摘要，且不遮挡评论与相似推荐

#### Scenario: 百科数据为空
- **WHEN** 歌曲百科接口返回空数据
- **THEN** 页面隐藏百科区块，其余内容照常展示

### Requirement: 红心数展示
系统 SHALL 在歌曲详情页展示当前歌曲的红心数量，并随当前歌曲切换更新。

#### Scenario: 切换到另一首歌
- **WHEN** 用户在播放器中切到另一首歌曲
- **THEN** 红心数更新为新歌曲对应的数值

#### Scenario: 红心数接口失败
- **WHEN** 红心数请求失败
- **THEN** 页面隐藏红心数，不显示错误占位，也不阻塞其他区块

### Requirement: 数据请求降级
系统 SHALL 在百科与红心数请求失败时不额外弹出错误提示，并保持详情页原有内容可用。

#### Scenario: 两个接口都失败
- **WHEN** 百科与红心数请求均失败
- **THEN** 详情页仅隐藏这两个新增区块，评论、相似推荐与播放器控件保持可用
