# Spec Delta

## Purpose

让用户的搜索输入被本地记录并可复用，减少重复输入；历史完全存于浏览器本地，与账号和登录态无关。

## ADDED Requirements

### Requirement: 搜索历史记录
系统 SHALL 在用户主动执行搜索时记录关键词，去重后按最近使用顺序保存，上限 20 条，超出丢弃最旧条目。

#### Scenario: 记录一次搜索
- **WHEN** 用户输入关键词并提交搜索
- **THEN** 该关键词出现在搜索历史最前，重复项只保留一条

#### Scenario: 空白不记录
- **WHEN** 用户提交空白或仅空格的关键词
- **THEN** 搜索历史不变

#### Scenario: 达到上限
- **WHEN** 搜索历史已有 20 条且用户搜索新词
- **THEN** 新词置顶，最旧一条被移除

### Requirement: 搜索历史展示与使用
系统 SHALL 在搜索入口展示历史词，点击后直接以该词发起搜索。

#### Scenario: 点击历史词
- **WHEN** 用户点击一条搜索历史
- **THEN** 搜索框填入该词并立即跳转到对应搜索结果

#### Scenario: 未登录可用
- **WHEN** 用户未登录时使用搜索历史
- **THEN** 历史展示与使用均正常，不触发登录提示

### Requirement: 搜索历史管理
系统 SHALL 允许用户删除单条历史与一键清空全部历史。

#### Scenario: 删除单条
- **WHEN** 用户点击某条历史的删除按钮
- **THEN** 仅该条被移除，其余顺序与内容不变

#### Scenario: 清空全部
- **WHEN** 用户确认清空历史
- **THEN** 历史列表为空，刷新后仍为空
