# Spec Delta

## Purpose

让用户在列表页与详情页之间往返时不丢失阅读位置，减少长列表重复滚动；同时保证进入新页面从顶部开始，避免沿用上一页位置。

## ADDED Requirements

### Requirement: 返回列表恢复滚动位置
系统 SHALL 在用户从列表页进入详情页再返回时，把该列表恢复到离开前的滚动位置。

#### Scenario: 歌单列表往返
- **WHEN** 用户在歌单详情滚动到中部，点进某首歌详情后返回歌单详情
- **THEN** 歌单详情回到离开前的滚动位置

#### Scenario: 搜索结果往返
- **WHEN** 用户在搜索结果页滚动后进入详情页再返回
- **THEN** 搜索结果页恢复离开前的滚动位置

### Requirement: 新导航回到顶部
系统 SHALL 在用户通过导航或标签切换进入不同页面时从顶部开始展示。

#### Scenario: 切换到新页面
- **WHEN** 用户从底部导航或顶部菜单切换到一个新的列表页
- **THEN** 新页面从顶部开始，不继承上一页的滚动位置

#### Scenario: 同一页不同参数
- **WHEN** 用户在同一路由上切换参数（如搜索不同关键词、歌单 tab 切换）
- **THEN** 页面从顶部开始，不沿用旧参数下的滚动位置
