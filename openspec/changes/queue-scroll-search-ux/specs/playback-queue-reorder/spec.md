# Spec Delta

## Purpose

让播放队列的顺序可由用户直接调整，并保证重排不打断当前播放；顺序跨刷新保持，使"接下来听什么"完全由用户掌控。

## ADDED Requirements

### Requirement: 队列拖拽重排
系统 SHALL 允许用户在播放列表中拖拽歌曲改变顺序，重排结果 MUST 跨页面刷新保持。

#### Scenario: 拖拽改变顺序
- **WHEN** 用户在播放列表中将一首歌拖到新位置
- **THEN** 列表按新顺序展示，且该顺序在刷新页面后仍保持一致

#### Scenario: 当前播放项被重排
- **WHEN** 用户拖拽的正是当前正在播放的歌曲
- **THEN** 播放不中断、曲目不变，队列中的当前项标记随该歌曲移动到新位置

### Requirement: 重排后的播放推进
系统 SHALL 在队列重排后按新顺序决定下一首与上一首。

#### Scenario: 重排后切下一首
- **WHEN** 用户重排队列后点击"下一首"
- **THEN** 播放新顺序中当前项之后的歌曲

#### Scenario: 随机模式不受影响
- **WHEN** 播放模式为随机
- **THEN** 重排仅改变队列展示顺序，随机选曲逻辑保持原行为
